# Farsana Capstone

This repository provides the structure for the capstone project and will hold the implementation, design artifacts, and recorded run outputs as the work evolves.

## Repository layout

- `src/` — Python code goes here.
- `docs/` — design documents (ADRs, canvaes) go here.
- `docs/adr/` — Architecture Decision Records.
- `docs/runs/` — saved LLM run outputs.
- `README.md` — front page of the repository.

## Project status

This is the initial project scaffold. The next steps will add the core implementation and the design documentation.
